# OFFBEAT · 不循常规

以翡翠色幻想天文馆为主题的个人博客：漂浮花园星球、实时 WebGL 星轨和萤火粒子、立体文章封面、玻璃展签与柯基看板娘。

## 本地启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

浏览器打开终端显示的本地地址。构建发布文件运行 `npm run build`，输出位于 `dist/`，可部署到静态网站托管平台。

## 自定义

- `src/articles.js`：文章、分类、日期、摘要和正文。当前六篇文章为原创示例内容。
- `src/main.js`：站点标题、个人介绍、导航与交互。
- `src/tokens.css`：基础配色和字体。
- `src/style.css`：排版、玻璃材质与响应式布局。
- `src/observatory.css`：幻想天文馆的场景布局、错落文章展签、微交互和状态样式。
- `src/observatory.js`：花园星球纹理、实时星轨、萤火粒子、宝石和指针视差。
- `src/world.js`：Three.js 场景、文章封面及柯基模型。
- `public/favicon.svg`：站点图标。

## 互动

鼠标悬停文章卡片可倾转；鼠标拖动、触屏横向滑动或左右方向键切换文章。点击卡片或翻转图标，只翻到背面查看摘要；点击背面的“开始阅读”才打开正文，“回到封面”恢复正面。背面展开期间暂停轮播。减少动态效果时直接切换正反面。拖动不会触发阅读，点击书签收藏，收藏保存在当前浏览器。顶部搜索支持 `Ctrl/Cmd + K`。右上角控制连续动画与环境音，环境音默认关闭。点击柯基可传球，减号可收起它。游乐场按钮切换三套宇宙配色。

默认尊重系统的减少动态效果设置。动画限制到约 30 帧，离开视口的场景不渲染，页面进入后台时停止绘制。WebGL 不可用时保留静态视觉与全部阅读功能。

这是纯前端博客，没有后台、登录或在线文章编辑器。文章更新需要修改源码后重新构建发布。收藏不会跨设备同步。

## 设计约束与真实状态

`AGENTS.md` 固定设计要求，`src/tokens.css` 是所有界面颜色的唯一来源。运行 `npm run check:design` 检查颜色变量、布局禁令和变量定义。当前采用深翡翠色、象牙白和浅金色，搭配实时三维建筑空间、大字排版与悬浮档案。

主场景为实时三维失重档案馆：扭转金属带、17 道八边形廊柱、金属地面、100 枚悬浮碎片与桌面 4,200 / 手机 1,600 个交互粒子。滚动改变镜头位置与观察目标，鼠标引导视角、排斥粒子，点击非交互区域产生扩散。文章区域降低背景亮度以维持可读性。旧花园插画保留在素材目录，但不再用于当前主场景。

3D 模块按需加载，实际初始化期间显示骨架屏并禁用依赖它的操作。失败时显示静态画面、提示与重试按钮；阅读和搜索不受影响。收藏写入失败会明确提示仅保留当前会话。搜索和收藏有空状态；音频初始化期间禁用重复操作。文章保存在本地代码中，不人为制造加载时间。

## 验证

```sh
node scripts/visual-check.mjs
node scripts/interaction-check.mjs
node scripts/gallery-check.mjs
```

验证脚本需要本地预览运行于 `http://127.0.0.1:5173/`，可用 `CHROME_PATH` 指定 Chromium 可执行文件；截图写入 `.preview/`，不随源码发布。

全屏背景使用独立 WebGL 场景：桌面 2,800 / 手机 1,100 个粒子、鼠标排斥、滚动视差、流动光带和四条空间轨道。背景像素比上限为 1，避免高分屏过度渲染。卡片支持最大 ±14° / ±18° 双轴倾斜、阻尼回正和指针反光，翻面时停止倾斜。

卡片画廊保留细横向滚动条，每 3 秒自动前进，到末尾返回开头。悬停、拖动、键盘聚焦、打开对话框、页面后台或离开视口时暂停；全局暂停动效及减少动态效果设置同样停止轮播。

文章展厅采用中央聚焦的透视弧线：卡片随横向滚动转向、缩放与升降。背景共用 WebGL 场景绘制古金色星盘（桌面 3,200 / 手机 1,100 个新增粒子）、刻度与三道流星尾迹。星盘随文章区的滚动位置移动，停用动效时仍保持位置正确。

整站采用连续空间构图：失重入口、章节导航、悬浮档案、星仪实验室、象牙色阅读册和大字页尾。实验室共用背景 WebGL 场景，不增加画布；鼠标改变观察角度，点击加速轨道，切换光谱同时改变全站强调色。无 WebGL 时保留静态星仪轮廓并禁用相关操作。

麻薯采用独立行为控制：闻球、观察鼠标、蓄力踢球、追球、庆祝、休息与摸头反馈；球有重力、地面反弹、滚动衰减和边界回弹。头部、步态、耳朵和尾巴平滑过渡，眨眼间隔有变化；眼睛高光随眨眼收缩。摸摸头和传球按钮支持手机与键盘，遵守全局暂停动效。行为及页面检查：`node scripts/pet-behavior-check.mjs`、`node scripts/pet-check.mjs`。

可按住麻薯身体拖动到屏幕任意位置；触屏同样可拖动，Alt + 方向键支持键盘移动。拖动不会触发传球，收起再展开保留本次浏览的位置，窗口缩放和气泡变高时会自动限制在可见范围内。鼠标停在附近时，观察动作结束后仍会继续自主踢球、追球。

麻薯支持拖拽抛掷：用松手前 100ms 的指针采样估算速度，重力驱动下落，四边碰撞损耗动能，地面摩擦使滑行逐渐停止。抓住可中断飞行；拖动取消不会抛出；全局暂停或收起时停止，减少动态效果时保留直接定位。物理检查：`node scripts/pet-physics-check.mjs`；浏览器抛掷检查：`node scripts/pet-throw-check.mjs`。
